# R Scripts

This folder contains all R scripts for the final project.

### Sub-directories 

- [1_attempt/](1_attempt): contains all scripts for attempt 1
- [2_attempt/](2_attempt): contains all scripts for attempt 2

### R Scripts
- `0_eda_clean.R`: Initial EDA, missingness analysis, and feature engineering (vegetarian, vegan, sweet, spicy, alcohol, luxury ingredients, n_ingredients, is_quick, days_since_published)
- `5_final_model_fit.R`: Fits the final selected model on the full training set
- `6_final_model_analysis.R`: Final model evaluation and analysis on the test set
