# Complex Recipes - Model Scripts

This folder contains model tuning scripts using the complex recipes (rec4, rec5).

### R Scripts
- `2_complex_recipes.R``: Defines rec4 (complex tree-based) and rec5 (complex distance-based)
- `3_bt_tune_rec4.R`: Boosted tree
- `3_en_tune_rec5.R`: Elastic net
- `3_ensemble_tune_rec5rec4.R`: Ensemble Model (MARS & Boosted Tree)
- `3_knn_tune_rec5.R`: KNN
- `3_lm_fit_rec5.R`: Linear regression
- `3_mars_tune_rec4.R`: MARS
- `3_nn_tune_rec5.R`: Neural network
- `3_rf_tune_rec4.R`: Random forest
- `3_svm_poly_tune_rec5.R`: SVM polynomial
- `3_svm_rad_tune_rec5.R`: SVM radial
- `3.5_model_runtimes.R`: Runtimes for complex recipes models
