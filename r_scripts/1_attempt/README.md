# 1st Attempt

This folder contains all scripts for the first modeling attempt.

### Sub-directories 

- [1a_simple/](1a_simple): Model tuning scripts using simple recipes (rec1, rec2, rec3)
- [1b_advanced/](1b_advanced): Model tuning scripts using complex recipes (rec4, rec5)

### R Scripts
- `1_initial_split.R`: 80/20 stratified split and 5-fold cross-validation with 3 repeats
- `4_model_analysis.R`: Model comparison and selection across all rec versions for attempt 1
