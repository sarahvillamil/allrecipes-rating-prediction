# Plots

This folder contains saved plot and table objects as .rda files.

- `target_var_analysis.rda`: Distribution and summary statistics of avg_rating
- `missingness.rda`: Missingness visualization and summary table
- `misc_plots.rda`: EDA plots for engineered features (n_ingredients, vegetarian, luxury, sweet, spicy, vegan, alcohol)
- `final_tbls_graphs.rda`: Tables and graphs for final fit
- `attempt1_rf_rec2_autoplot.rda`: Autoplot for RF attempt 1 hyperparameters
- `attempt1_results_table.rda`: Model results for attempt 1
- `attempt1_results_plot.rda`: Model results plot for attempt 1
- `attempt2_results_table.rda`: Model results for attempt 2
- `attempt2_results_plot.rda`: Model results plot for attempt 2
- `attempt1_mars_rec2_autoplot.rda`: Autoplot for MARS attempt 1 hyperparameters
- `attempt1_ensemble_rec2_autoplot.rda`: Autoplot for Ensemble (KNN & BT) attempt 1 hyperparameters
