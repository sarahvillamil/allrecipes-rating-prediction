# Results

This folder contains all tuned model result files saved as .rda objects.

- `simple_runtimes.rda`: Attempt 1 runtimes for simple models
- `final_fit.rda`: Final fit to testing: Boosted tree model (rec2)
- `complex_runtimes.rda`: Attempt 1 runtimes for complex models
- `attempt2_rf_rec2_tuned.rda`: Random forest attempt 2 (rec2)
- `attempt2_rf_rec2_tictoc.rda`: Random forest attempt 2 runtime
- `attempt2_mars_rec2_tuned.rda`: MARS attempt 2 (rec2)
- `attempt2_mars_rec2_tictoc.rda`: MARS attempt 2 runtime
- `attempt2_ensemble_rec2_tuned.rda`: Ensemble attempt 2 (rec2)
- `attempt2_ensemble_rec2_tictoc.rda`: Ensemble attempt 2 runtime
- `attempt2_bt_rec2_tuned.rda`: Boosted tree attempt 2 (rec2)
- `attempt2_bt_rec2_tictoc.rda`: Boosted tree attempt 2 runtime
- `attempt1_svm_rad_rec5_tuned.rda`: SVM radial (rec5)
- `attempt1_svm_rad_rec3_tuned.rda`: SVM radial (rec3)
- `attempt1_svm_poly_rec5_tuned.rda`: SVM polynomial (rec5)
- `attempt1_svm_poly_rec3_tuned.rda`: SVM polynomial (rec3)
- `attempt1_rf_rec4_tuned.rda`: Random forest model (rec4)
- `attempt1_rf_rec2_tuned.rda`: Random forest model (rec2)

- `attempt1_null_rec1_fit.rda`: Null model baseline (rec1)
- `attempt1_nn_rec5_tuned.rda`: Neural network  (rec5)
- `attempt1_nn_rec3_tuned.rda`: Neural network (rec3)
- `attempt1_mars_rec4_tuned.rda`: MARS (rec4)
- `attempt1_mars_rec2_tuned.rda`: MARS (rec2)
- `attempt1_lm_rec5_fit.rda`: Linear regression  (rec5)
- `attempt1_lm_rec3_fit.rda`: Linear regression (rec3)
- `attempt1_knn_rec5_fit.rda`: KNN  (rec5)
- `attempt1_knn_rec3_fit.rda`: KNN (rec3)
- `attempt1_ensemble_rec5rec4_tuned.rda`: Ensemble: MARS & Boosted tree (rec5, rec4)
- `attempt1_ensemble_rec3rec2_tuned.rda`: Ensemble: KNN & Boosted tree (rec3, rec2)
- `attempt1_en_rec5_fit.rda`: Elastic net (rec5)
- `attempt1_en_rec3_fit.rda`: Elastic net (rec3)
- `attempt1_bt_rec5_fit.rda`: Boosted Tree (rec5)
- `attempt1_bt_rec3_fit.rda`: Boosted Tree (rec3)
